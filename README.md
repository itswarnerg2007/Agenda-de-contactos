# Agenda de Contactos en C++

Una aplicación de consola desarrollada en C++ que permite gestionar una agenda de contactos mediante un menú interactivo.

## Funcionalidades

- Agregar contactos
- Buscar contactos por nombre
- Mostrar todos los contactos registrados
- Modificar contactos
- Eliminar contactos
- Salir de la aplicación

## Tecnologías

- C++
- Visual Studio

## Conceptos aplicados

- Arreglos
- Ciclos (`for` y `do-while`)
- Condicionales (`if`)
- `switch`
- Entrada y salida estándar (`cin` y `cout`)

## Estructura del proyecto

```
Agenda.cpp
Agenda de contactos.sln
Agenda de contactos.vcxproj
Agenda de contactos.vcxproj.filters
README.md
```

## Cómo ejecutar

1. Clona este repositorio.
2. Abre el archivo `Agenda de contactos.sln` con Visual Studio.
3. Compila el proyecto.
4. Ejecuta la aplicación.
